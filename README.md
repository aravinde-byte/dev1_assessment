# Python Developer Assessment

## Project Overview
This repository contains solutions for the Python Developer Assessment. Tasks include basic Python exercises, Git & GitHub workflows, code style, data structures, OOP, debugging, and API interaction.

## Tasks Completed
- Task 1.1: Hello World
- Task 1.2: GitHub Repository Setup & First Branch
- Task 1.3: Code Style & Linting
- Task 2.1: Data Structures & Algorithms
- Task 2.2: Object-Oriented Programming
- Task 2.3: Debugging & Error Handling
- Task 3.1: API Interaction

## Instructions
- Clone this repository: `git clone https://github.com/aravinde-byte/python-dev-assessment.git`
- Run Python scripts in your preferred IDE or terminal.
- Use `pip install -r requirements.txt` if additional packages are needed.

## Reflections
- Most challenging: Debugging empty lists and handling errors gracefully.
- Most interesting: Working with APIs and learning structured OOP in Python.
- Learned: Proper Git branching workflow, code linting with Black & Flake8, and exception handling.
